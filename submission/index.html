Content Refresh Opportunity Scoring

A machine-learning approach for prioritizing pages for content review

Abstract

This project investigates which web pages should be prioritized for content refresh using observed search performance and opportunity signals. An anonymized dataset of 30,000 pages was used to build a binary classification model for identifying pages with declining performance.

A Random Forest classifier using 38 features was evaluated with a time-aware 80/20 split. The model achieved an F1 score of 0.837 on the test split, compared with 0.320 for the Week-4 baseline.

The results provide a stronger directional signal for prioritizing pages for review in this dataset. The model is intended as a decision-support tool and does not automatically determine whether a page should be refreshed.

1. Introduction / Problem Statement

Content teams often need to decide which pages should be reviewed first when resources for content refresh are limited.

The research question for this project is:

Which pages should be prioritized for content refresh based on their observed search performance and opportunity signals?

The decision supported by this analysis is the prioritization of pages for content review and potential refresh. The model is not intended to automatically decide that a page must be refreshed.

2. Data

The analysis uses an anonymized FlyRank content-refresh dataset containing 30,000 page-level observations.

The modeling dataset contains search, content, engagement, freshness, and traffic-related signals. The analysis uses anonymized information and does not expose client names, private queries, credentials, or raw private exports.

Target

A binary target was created from the observed trend direction. Pages with a trend direction of "down" were assigned to the declining class.

Important Data Considerations

The analysis focuses on observed page-level signals available for modeling. Identifiers and outcome-related fields that could create data leakage were excluded from the final feature set.

3. Methodology

Model

A Random Forest classifier was used to identify pages showing a declining trend.

Features

The final model used 38 features covering search demand, competition, content characteristics, historical traffic, engagement, content age, freshness, click-through rate (CTR), average search position, and related signals.

Validation Design

The model was evaluated using a time-aware 80/20 split. The earlier 80% of observations were used for training, while the later 20% were used for testing.

This design was chosen to provide a more realistic evaluation than a random split and to reduce the risk of overly optimistic validation results.

Leakage Audit

The final feature set was checked for obvious leakage fields. Trend direction, trend percentage, the target label, content IDs, and client IDs were excluded from the model features.

4. Results

The Random Forest achieved an F1 score of 0.837 on the time-aware test split.

The Week-4 baseline measured an F1 score of 0.320 on the comparison evaluation.

Interpretation: The observed result suggests that the Random Forest provides a stronger directional signal for identifying declining pages in this dataset.

5. Limitations & Honest Framing

This analysis is observational. The model identifies patterns in the available data but does not establish causal relationships.

In particular, a high decline probability does not prove that refreshing a page will cause its search performance to improve.

The model should therefore be treated as a decision-support and prioritization tool. Human reviewers should consider content quality, search intent, relevance, freshness, and other contextual factors before taking action.

6. Ranked Recommendations

The action playbook ranks pages according to their observed model signal for decline.

Recommended Workflow

  1. Review pages with the strongest decline signal first.
  2. Check recent impressions, clicks, search position, and engagement.
  3. Review content relevance, search intent, and freshness.
  4. Decide whether refresh, monitoring, or another action is appropriate.
  5. Keep the final decision with a human reviewer.

Higher model scores indicate higher review priority; they do not guarantee that a content refresh will produce an improvement.
