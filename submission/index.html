Content Refresh Opportunity Scoring

A machine-learning approach for prioritizing pages for content review

0.837 Random Forest F1
0.320 Week-4 baseline F1
30,000 Pages
38 Model features

Abstract

This project investigates which web pages should be prioritized for content refresh using observed search performance and opportunity signals. An anonymized dataset of 30,000 pages was used to build a binary classification model for identifying declining pages. A Random Forest model using 38 features was evaluated with a time-aware 80/20 split. The model measured an F1 score of 0.837 on the test split, compared with 0.320 for the Week-4 baseline. The results provide a stronger directional signal for prioritization in this dataset and are intended for decision-support and human review.

1. Introduction / Problem Statement

Content teams often need to decide which pages should be reviewed first when resources for content refresh are limited.

The research question for this project is:

Which pages should be prioritized for content refresh based on their observed search performance and opportunity signals?

The decision supported by this analysis is the prioritization of pages for content review and potential refresh. The model is not intended to automatically decide that a page must be refreshed.

2. Data

The analysis uses an anonymized FlyRank content-refresh dataset containing 30,000 page-level observations.

The modeling dataset contains search, content, engagement, freshness, and traffic-related signals. The analysis uses public-safe, anonymized information and does not expose client names, private queries, credentials, or raw private exports.

Target

A binary target was created from the observed trend direction. Pages with a trend direction of "down" were assigned the declining class.

Important data considerations

The analysis focuses on observed page-level signals available for modeling. Identifiers and outcome-related fields that could create leakage were excluded from the final feature set.

3. Methodology

Model

A Random Forest classifier was used to identify pages showing a declining trend.

Features

The final model used 38 features covering search demand, competition, content characteristics, historical traffic, engagement, content age, freshness, CTR, average position, and related signals.

Validation design

The model was evaluated using a time-aware 80/20 split. The earlier 80% of observations were used for training and the later 20% were used for testing.

This design was chosen to provide a more realistic evaluation than an easier random split and to reduce the risk of overly optimistic validation results.

Leakage audit

The final feature set was checked for obvious leakage fields. Trend direction, trend percentage, the target label, content IDs, and client IDs were not used as model features.

4. Results

The Random Forest measured an F1 score of 0.837 on the time-aware test split.

The Week-4 baseline measured an F1 score of 0.320 on the comparison evaluation.

5. Limitations & Honest Framing

This analysis is observational. The model identifies patterns in the available data but does not establish causal relationships.

In particular, a high decline probability does not prove that refreshing a page will cause its search performance to improve.

The model should therefore be treated as a decision-support and prioritization tool. Human reviewers should consider content quality, search intent, relevance, freshness, and other contextual factors before taking action.

6. Ranked Recommendations

The action playbook ranks pages according to their observed model signal for decline.

Recommended workflow

  1. Review pages with the strongest decline signal first.
  2. Check recent impressions, clicks, position, and engagement.
  3. Review content relevance, search intent, and freshness.
  4. Decide whether refresh, monitoring, or another action is appropriate.
  5. Keep the final decision with a human reviewer.

Higher model scores indicate higher review priority; they do not guarantee that a refresh will produce improvement.
